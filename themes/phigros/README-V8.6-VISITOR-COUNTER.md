# V8.6 — 全站访问量统计

- Moe Counter 使用统一 ID（默认 `dmorest.github.io`）。
- 首页最后一屏的 MISC 区域与 About 页面显示计数器。
- 其他页面（文章、分类、归档、标签等）加载一个不可见的计数请求，因此也会计入同一计数器。
- 每次页面加载会给请求追加缓存破坏参数，尽量避免浏览器缓存导致请求未发出。
- 可在主题 `_config.yml` 的 `visitor_counter` 中调整 `enable`、`id` 和 `theme`。

说明：这是基于 Moe Counter 图片请求的页面访问计数，不是去重后的独立访客数；浏览器拦截请求或计数服务不可用时可能漏计。
