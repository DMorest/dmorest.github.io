# v8.2 changes

- Folder contents on post pages are ordered strictly by publication date (newest first).
- The current article is no longer forcibly pinned to the top; it appears at its chronological position.
- On screens <= 780px, FOLDER_INFORMATION becomes a collapsed off-canvas side drawer with a small FOLDER/CLOSE tab, so long category lists never push FILE_CONTENT down the page.
- Desktop two-column post layout is unchanged.
